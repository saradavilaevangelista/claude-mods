# Effort Picker

Before each message you send, a quick Haiku call reads it and picks the reasoning effort:

- a long job you're walking away from: **xhigh**
- anything that could cost you money or a client, or anything written in your voice: **high**
- a quick question: **low**
- anything else: left at the session's own setting

When the level changes, you get a pop-up in Portuguese and the reply opens with one line saying why. The status line shows the current level. If a different model would do the job better, the reply says so, but the mod never switches models.
