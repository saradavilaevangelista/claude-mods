# Replay Theater

After Claude edits your files, a line appears above the chat ("3 changes in 2 files") with a **▶ Replay** button. Press it and a pane walks you through every change, one at a time, like track changes in Word: the old lines crossed out in red, the new lines in green right under them, with a little unchanged context around them.

Use **◀ Back** and **Next ▶** to move, **Done** to close. `/replay` reopens the last set any time. Edits made by subagents aren't included.
