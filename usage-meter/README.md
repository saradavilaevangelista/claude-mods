# Usage Meter

One line above the chat: how full this chat's context is, and how much of your 5-hour and weekly limits you've used. Figures turn yellow at 70% and red at 90%; a dash means no reading yet (it fills in after the first reply).

If more than an hour has passed since your last message or Claude's last reply, sending a message asks first, because the cached chat has expired and Claude rereads the whole thing. Choose "Don't send" and your text goes back in the prompt box.
